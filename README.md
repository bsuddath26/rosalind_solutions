# Rosalind Solutions
Python solutions for 10 Rosalind bioinformatics problems completed for GENE 5120.
All functions are in `rosalind_functions.py`.
## Problems
- **DNA:** Counts DNA nucleotides.
- **RNA:** Converts a DNA sequence into RNA.
- **REVC:** Finds the reverse complement of DNA.
- **GC:** Finds the FASTA sequence with the highest GC content.
- **HAMM:** Counts the differences between DNA sequences.
- **PROT:** Translates RNA into its protein sequence.
- **SUBS:** Finds the positions of a motif in DNA.
- **PRTM:** Calculates the mass of a given protein.
- **REVP:** Finds palindromes in DNA.
- **TRAN:** Calculates the transition/transversion ratio.
